🍎 Mac 설치 가이드

⚠️ Mac 사용자 필독

다운로드 후 "손상되었습니다" 오류가 나오면 아래 단계를 따라주세요.

1 터미널 열기

Spotlight 검색(⌘ Cmd + Space)에서 "터미널" 입력 후 Enter

2 아래 명령어 복사 → 붙여넣기 → Enter

xattr -d com.apple.quarantine ~/Downloads/Matching*.dmg

💡 이 명령어는 Apple 보안 속성만 제거합니다. 파일은 안전합니다.

3 DMG 파일 더블클릭

Downloads 폴더에서 Matching-Data-Extractor-1.0.0-mac.dmg 파일을 더블클릭

4 Applications 폴더로 드래그

열린 창에서 앱 아이콘을 Applications 폴더로 드래그하여 설치 완료!

✅ 설치 완료 후 바로 실행 가능하며, 데이터는 기존 Supabase 설정을 그대로 사용합니다.

💻 Windows 설치 가이드

1 설치 파일 실행

다운로드한 .exe 파일을 더블클릭하여 설치를 시작하세요.

2 설치 진행

설치 마법사의 안내를 따라 설치를 완료하세요.

✅ 설치 완료 후 바로 실행 가능합니다.
